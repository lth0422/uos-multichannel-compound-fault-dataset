# CH0 포락선 FFT 그림

- 대상: 해당 베어링·결함의 6 RPM × 8 로터 조건 = 48파일
- 분석 구간: 원파일 60~180초
- 포락선 carrier 대역: 2~7 kHz
- 처리: 4차 Butterworth 대역통과 → Hilbert 포락선 → Welch 스펙트럼
- 파란색: 파일별 최댓값을 1로 맞춘 포락선 FFT
- 빨간색: 회전주파수 1X와 레이블상 기대되는 결함주파수 1·2·3차 고조파
- 자홍색: 복합 결함의 쌍별 합·차 주파수 후보
- `individual/`: 파일별 원본 크기 PNG 48개
- `contact_sheet.png`: 48개 그림 전체 축소본

정규화 그림은 주파수 위치 확인용이며 파일 사이의 절대 진폭 비교에는 사용하지 않음.
회전주파수 최종 판정은 원신호 FFT 결과를 사용함.
